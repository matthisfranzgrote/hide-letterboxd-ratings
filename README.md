**Hide Letterboxd Ratings** is a simple Firefox extension that blurs and obfuscates the rating curve, user reviews and friend activity on film pages.
Avoid getting spoiled or setting expectations when looking at (unwatched) films.

## Features
- **Global Toggle**: Quickly turn the obfuscation on or off globally via the extension popup.
- **Auto-Reveal for Watched Films**: Configure the obfuscation to automatically turn off for films you have marked as watched.   
-  **Obfuscation by Default**: The rating curve often catches the eye after page load. This extension obfuscates it immediately once it appears on the page.

## Usage
### Temporary (until browser reload)
- Clone this repo
- Open `about:debugging#/runtime/this-firefox` (or Navigate via `Extensions and Themes > Gear Icon ⚙ > Debug Add-ons`)
- Click `Load Temporary Add-on...`
- Select the `manifest.json` file

### Permanent
- Clone this repo and zip the contents or download the most recent release
- Open `about:addons`
- Click the `Gear Icon ⚙ > Install Add-on From File...`
- Select the zip
